# Biological model contract

## Status

Model identifier: `rat-cortical-patch-v2`  
Schema version: `1`  
Implementation: `src/model.js`, `src/morphology.js`

This contract describes the first reduced-order cortical specimen. It does not define every future BiologicalSetup entity.

## Coordinate system and units

The specimen uses a right-handed local tissue frame.

- `x`: lateral position in micrometres, 0–200 µm.
- `y`: lateral position in micrometres, 0–200 µm.
- `z`: optical depth in micrometres, 0–40 µm.
- time: seconds.
- membrane voltage: millivolts.
- synaptic and applied drive: reduced current in millivolts per second.
- calcium: bounded reduced intracellular state, not a calibrated concentration.
- indicator: bounded reduced fluorescence-driving state.
- metabolism and stress: dimensionless fractions.

The visual field represents a shallow optical volume in a larger piece of tissue. Processes may enter or leave the field.

## Explicit entities

The first preset contains 50 explicit neurons:

- 40 excitatory;
- 10 inhibitory;
- heterogeneous position, depth, soma geometry, dendrites, axon, excitability, calcium kinetics and connections.

The remaining tissue is represented with lower-detail background nuclei and neuropil fibres. Those background forms are observation support, not additional electrophysiological agents.

## Neuronal dynamics

Each explicit neuron has a reduced leaky integrate-and-fire state.

For a non-refractory neuron:

```text
dV/dt = (Vrest − V) / τm
        + Itonic
        + Iexternal
        + Isynaptic
        + Inoise
        + Istress
        − Iadaptation
        − Imetabolic
```

When `V` reaches the neuron-specific threshold:

- voltage resets;
- a short refractory period begins;
- adaptation increases;
- intracellular calcium increases;
- metabolic reserve decreases slightly;
- outgoing synaptic events are scheduled after connection-specific delays;
- a visual propagation event is emitted.

This is a qualitative network model. It does not model ion-channel conductances, dendritic cable equations, receptor kinetics, extracellular ion concentrations or detailed synaptic biochemistry.

## Connectivity

Connections are generated deterministically from the specimen seed.

- Nearby targets are more likely than distant targets.
- Excitatory neurons emit positive reduced synaptic drive.
- Inhibitory neurons emit negative reduced synaptic drive.
- Every connection has an explicit delay and sign.
- The baseline parameter regime is tuned for sparse spontaneous activity rather than runaway recurrence.

The network is synthetic. It is not a reconstruction of a measured cortical microcircuit.

## Calcium and indicator state

A spike increases a reduced intracellular calcium state. Calcium then relaxes toward a baseline with neuron-specific clearance time.

The displayed calcium indicator is a separate state driven toward a saturating function of calcium. Rise and decay constants are distinct so fluorescence can lag and outlast voltage events.

The model intentionally preserves this ordering:

```text
stimulation → depolarization → spike → calcium increase → indicator response
```

Calcium values are not currently expressed in nanomolar units and must not be labelled as calibrated concentration.

## Metabolism, stress and deformation

Each neuron has:

- a metabolic reserve that is consumed slightly by activity and slowly recovers;
- a stress state increased by strong or repeated poking and slowly relaxed;
- a short-lived deformation state used by the mechanical rendering.

These variables condition movement and appearance but are not validated pathway models.

## Morphology

Each neuron has:

- an irregular soma contour;
- a nucleus;
- multiple branched dendritic paths;
- one axonal path;
- depth along each process;
- mitochondria and vesicle populations.

Morphology is deterministic and procedural. It is constrained to plausible scales and connectivity roles but is not traced from microscopy or generated by a validated morphogenesis model.

## Subcellular traffic

Mitochondria and vesicles move along soma-local and neurite-local paths. Motion is deterministic for a fixed seed and is modulated by metabolic state.

This traffic is perceptual and explanatory. The model does not currently represent molecular motors, microtubule polarity, fusion/fission chemistry, vesicle pools at individual synapses or organelle mass balance.

## Poke semantics

A poke is a compound reduced-order perturbation:

- local membrane deformation;
- brief applied current;
- small stress increment;
- selection of the contacted explicit neuron.

A normal deliberate poke drives a non-refractory neuron across threshold. Weak dragging can remain subthreshold. Repeated pokes can generate repeated firing after refractory recovery.

The poke is not a calibrated force measurement, patch-clamp protocol or mechanosensitive-channel model.

## Determinism and reproducibility

A fixed specimen seed determines:

- entity positions;
- morphology;
- cell parameters;
- connectivity;
- spontaneous event sequence;
- background structures.

Automated tests require repeated creation from the same seed to produce the same structural specimen.

## Numerical method

The default fixed model step is 2 ms. Browser frames may perform multiple fixed steps. Wall-clock rendering and biological stepping are separate.

Required numerical invariants:

- finite voltages and currents;
- calcium remains within the documented reduced range;
- metabolism remains between 0.35 and 1;
- stress remains between 0 and 1;
- synaptic event queues expire;
- default spontaneous activity remains bounded over the acceptance interval.

## Explicit omissions

The first model omits:

- glia as explicit agents;
- detailed synapses and receptor types;
- conductance-based electrophysiology;
- realistic cortical lamination;
- extracellular diffusion fields;
- vascular supply;
- gene expression;
- growth and plasticity;
- cell death pathways;
- quantitative species, age and preparation differences;
- calibrated pharmacology;
- tissue mechanics.

These omissions must remain visible in claims and specimen documentation.
